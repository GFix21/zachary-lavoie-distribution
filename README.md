# Zachary Lavoie Distribution Website

Website for Distribution Zachary Lavoie inc., distributor of Bergeron and St-Guillaume cheeses in Champlain, Quebec.

## Features
- Bilingual (French first, English toggle)
- Main page with company info and spokesperson Zachary (green screen alpha demo)
- Trisha’s Gift Baskets store with 5 basket types + Mega Poutine Basket (5 sizes)
- Basket images generated, contents lists, pricing based on contents
- Simple cart and checkout (Interac e-Transfer or contact for payment)
- No returns / no refunds policy. Issues? Chat with Ms. Jeezy for a free gift!
- Interactive chatbot "Ms. Jeezy" - chatty, pushy, engaging, talks about everything, lures into conversation, offers free cheese samples and free gift address form
- Chat icon wiggles and pops for attention

## Setup
Clone the repo, add images to /images/ folder (spokesperson and baskets), open index.html.

Images are prepared and can be uploaded.
